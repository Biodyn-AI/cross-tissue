Cross-tissue benchmark rebuild: plos-one-rebuild-v2.0.0

Prepared local release candidate; publication is not asserted by this file.

This version evaluates scGPT whole-human and Geneformer V2-104M on kidney,
lung and pooled immune Tabula Sapiens contexts. The complete design contains
57 model jobs and 312 saved budget snapshots, including continuous scGPT and
immune-organ sensitivity arms. Primary budgets are 30, 50, 100, 200, 500 and
1,000 cells. Resampling uncertainty is conditional on the fixed atlas pools,
references, preprocessing, checkpoints and seven-probe menu.

The replicated paired comparisons do not support the earlier sharp decrease
in transfer regret between 30 and 100 cells. Native context-specific candidate
universes retain high-budget transfer loss; strict common-candidate results
change that loss and its uncertainty. These are operational selection and
calibration findings, not an isolated causal effect of tissue or architecture.

The release assets comprise S1 Code, S1--S7 Data, exact frozen sparse model
inputs and saved candidate-score matrices. The supporting archives preserve
per-chain measurements, every scalar degree-null draw, individual diagnostic
observations, figure source points, identities and execution provenance.
The asset inventory and SHA256 file identify the exact supplied bytes.

Reproduction scope is explicit. Fresh extraction reruns the statistical
processing and figure/numerical-registry generation using supplied model and
diagnostic measurements. Input restoration verifies ordered observation and
feature identities and sparse-array component hashes for all three contexts.
Those checks do not rerun all pretrained models. Four independent legacy
first-30-cell snapshot replays match all 158 compared artifact entries exactly;
later inherited accumulators were not independently replayed. Restored H5AD
serialization need not have the original file-byte hash.

Full model execution additionally requires matching separately acquired model
checkpoints, dictionaries, regulatory references and the documented production
runtime. Exact scGPT execution source and its original MIT notice are supplied.
Tabula Sapiens/CELLxGENE expression arrays retain CC BY 4.0 attribution and
provider metadata. Author code licensing does not replace third-party terms.

Earlier exploratory files are retained for provenance and are superseded for
the rebuilt benchmark. The root README explains which workflow to use.
No journal correspondence or related-manuscript copy is part of this proposed
data/code release.
